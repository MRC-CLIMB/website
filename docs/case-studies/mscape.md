CLIMB infrastructure provides the computing platform for the UKHSA Metagenomics Surveillance and Analysis Programme (mSCAPE), where researchers can run reproducible data analysis pipelines, and get access to computing and storage capacity.

mSCAPE is led by the UK Health Security Agency (UKHSA), as part of the
UKHSA pathogen genomics strategy. It brings together a
consortium of NHS organisations and academic partners to monitor trends
and epidemiology in the emergence and spread of infections.

The programme has been in development since March 2022.
